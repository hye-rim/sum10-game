# 합 10 지우기 🔟

판에 깔린 숫자를 직사각형으로 드래그해서 **합이 딱 10**이 되면 지워지는 퍼즐. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 서버 없이 `index.html` + `logic.js` + `game.js` 만으로 돌아갑니다.

- **판**: 12행 x 10열, 칸마다 1~9. 판 전체 숫자의 합은 항상 10의 배수(이론상 다 지울 수 있음)
- **지우기**: 손가락(마우스)을 눌러 끌면 직사각형 상자가 생기고 모서리에 합이 보인다(10 미만 노랑 · 정확히 10 초록 · 초과 빨강). 손을 떼면 합이 10 이고 숫자가 두 칸 이상일 때 지워진다. 틀리면 합을 알려 준다
- **끌 때 오조작 줄이기**: 칸 사이 틈까지 계산해 손가락 위치를 칸에 맞추고(판 오른쪽·아래로 갈수록 한 칸씩 밀리던 것을 바로잡음), 끄는 중에는 칸 경계에서 손가락이 조금 흔들려도 옆 칸으로 튀지 않게 지금 칸을 `STICKY`(0.2칸)만큼 더 잡아 둔다
- **빈칸은 0**: 지운 자리는 0 으로 세어서 판이 비어 갈수록 넓은 영역을 잡을 수 있다
- **점수**: (지운 칸 수 + 3칸부터 칸 수-2 만큼 보너스) x 콤보 배수. 직전에 지운 지 3초 안이면 콤보가 이어지고, 콤보 1~2 는 x1 · 3~4 는 x2 · 5 이상은 x3
- **끝**: 60초가 다 되거나, 더 지울 곳이 없으면 끝. 최고 점수는 `sum10Best` (로비 표시용)
- 💡 힌트: 지울 수 있는 작은 영역을 점선으로 보여 준다 (한 판에 3번)
- 튜토리얼(`?tutorial=1`)에서는 읽는 동안 끝나지 않게 시간이 600초

규칙은 `logic.js`(`LOGIC_SUM10`, 화면 없이 Node 로 시험), 화면·입력·소리는 `game.js`. 시험은 `node --test`(`test/logic.test.js`): 새 판의 크기·숫자 범위·합이 10의 배수·처음부터 지울 곳이 있음, 합 10 영역 지우기·모서리 순서·틀린 합·빈칸 0·한 칸/빈 영역·범위 밖 거절, 지울 곳 찾기가 느린 전수 검사와 같음, 점수·콤보 배수, 힌트대로만 두면 항상 끝나고 지운 칸 수가 맞음.
